in the repository (`package.json`, installed `node_modules/*/package.json`, source files, the
`corpus/` directory and documentation preserved in Git history). Where permission or authorship
could not be verified from the repository, the item is explicitly marked **to be confirmed by the
submitter** rather than claimed.

## 2. Model/API service

- **InferHub** — the OpenAI-compatible inference marketplace that serves the vision and text
  models used by the product (for example `ag/gemini-3.8-flash-high` and `zai/glm-4.6v`; see
  `src/domain/config.ts`). The product also supports a user-supplied key (BYOK) and an edge proxy
  (`api/analyze.ts`, `worker/worker.js`, `proxy/modal_app.py`). The tool name `fireworks` in
  `.github/fireworks/` is historical: that code now targets an InferHub-compatible endpoint.

No photograph of a real, identified student paper is included in the repository. The names that
appear in `corpus/copies-demo.json` and in the demo story (for example "Jordan", "Léa M.", "Noé B.",
"Inès D.") are **fictional, anonymized labels** for synthetic demo papers; they do not identify real
students, and no personal information about a real person is represented in the demo data. A
documented protocol for collecting real papers with appropriate permission is in
[`corpus/README.md`](corpus/README.md); it has not been carried out in this submission.

The generated images are produced inside this project by `scripts/generer-copies.py`; the submitter
has permission to use them as project-generated assets. The recorded model answers in
`corpus/reponses/` were produced with the InferHub API for this project. The Caveat and DejaVu fonts
are referenced by path only and are not redistributed here; their licences must be checked by the
submitter before this generator is redistributed with font files. The design mockups referenced in
`corpus/README.md` are not included in this repository and are not part of the submission.
